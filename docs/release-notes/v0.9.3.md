# v0.9.3 — Player and navigation refinements

This release brings the latest PlxNative changes to the 0.9 line, including finer subtitle placement, remembered playback versions, and refinements to player and library navigation.

## What's new

- **More precise subtitle placement.** Video Frame, TV Screen, and Custom positions can be adjusted from 20 px to 200 px in 5 px steps.
- **Remembered playback version.** The player remembers the selected version for each item and profile. Subtitle position distance preferences are shared between Player and the main Settings screen.
- **Player and library refinements.** The player clock follows HUD visibility and HDR overlay brightness. Home and library navigation improves cursor and D-pad focus, poster scrolling, and hold-to-open behavior.

## Fixed

- **Player controls and menus.** Focus and press feedback now apply more consistently to player controls. Closing subtitle, audio, More, chapter, and info menus restores the intended playback state; returning from Go to Show returns to the active player session.
- **Poster navigation.** Cursor focus and scrolling are corrected across Home, Movies, TV Shows, and Recommended shelves, including the final row and hold-to-open menus.
- **Account navigation.** Profile changes can return to the previous screen, sign-out asks for confirmation, and expanded account controls respond across their full area.
- **Subtitle glyphs.** SF Pro Text now includes the musical-note glyph used by subtitles.

## Compatibility

No release-specific playback test on a television is recorded for this version. The technical audit reports package and static firmware checks; those checks do not establish that video playback works on a television.

## Installing

Download **com.beb.plxnative_0.9.3_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.beb.plxnative_0.9.3_arm.ipk
```

[Installing and checking a download](https://github.com/fingers986/plx-native/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.9.3](https://github.com/fingers986/plx-native/blob/main/docs/release-audits/v0.9.3.md).
