# v0.9.2 — Subtitle font choices

This release adds font choices for client-rendered subtitles, alongside the subtitle size and position controls.

## What's new

- **Subtitle fonts.** Choose Inter, Open Sans, or SF Pro Text in Settings > Playback > Subtitle Font. The choice is saved and used by the player; subtitles remain bold by default. Authored ASS/SSA styling is preserved.

## Compatibility

No release-specific playback test on a television is recorded for this version. The technical audit reports the package and static firmware checks; those checks do not establish that video playback works on a television.

## Installing

Download **com.beb.plxnative_0.9.2_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.beb.plxnative_0.9.2_arm.ipk
```

[Installing and checking a download](https://github.com/fingers986/plx-native/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.9.2](https://github.com/fingers986/plx-native/blob/main/docs/release-audits/v0.9.2.md).
