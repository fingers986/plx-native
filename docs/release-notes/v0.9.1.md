# v0.9.1 — Subtitle size and position controls

This release makes subtitle size easier to choose in small increments and restores direct D-pad adjustment for Custom subtitle position in the player.

## What's new

- **Subtitle size choices.** Choose a percentage from 80% to 180% in 5% steps. The player opens the size capsule so the value can be adjusted with the D-pad.
- **Custom subtitle position.** The player’s Custom position capsule responds to D-pad left and right, alongside the existing on-screen controls.

## Compatibility

No device playback test for this release is recorded here. The release audit reports what CI measured from the package; its static firmware checks do not establish that video playback works on a television.

## Installing

Download **com.beb.plxnative_0.9.1_arm.ipk** and install it with the [Homebrew Channel](https://github.com/webosbrew/webos-homebrew-channel) or [dev-manager-desktop](https://github.com/webosbrew/dev-manager-desktop). You do **not** need a rooted TV.

Nothing in this distribution chain is signed, so this sha256 is what tells you the file you have is the file published here:

```
__IPK_SHA256__  com.beb.plxnative_0.9.1_arm.ipk
```

[Installing and checking a download](https://github.com/fingers986/plx-native/blob/main/docs/install-and-verify.md) covers the other assets, how to check the hash on each platform, and the Developer Mode expiry that uninstalls your apps. This package bundles FFmpeg under LGPL-2.1-or-later and its complete corresponding source is attached to this release. Exactly what was built, verified and shipped is in the [technical audit for v0.9.1](https://github.com/fingers986/plx-native/blob/main/docs/release-audits/v0.9.1.md).
