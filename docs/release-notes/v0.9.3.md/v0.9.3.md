# v0.9.3 — Player and navigation refinements

This update brings the latest player and browsing improvements from main to the 0.9 maintenance line, alongside a wider range for subtitle placement.

## What's new
- **Subtitle placement range.** Video Frame, TV Screen, and Custom distances can be set from 20 px to 200 px in 5 px steps.
- **Remembered playback version.** The selected playback version is remembered for each item and profile, so the next play uses the version chosen most recently.
- **Clock and overlay behavior.** The clock is available across the app, follows the player HUD's visibility, and dims with the HDR overlay setting.
- **Subtitle glyph support.** The bundled subtitle font assets include improved support for musical-note symbols.

## Fixed
- Player menus and chapter/info actions now return to playback consistently, including when returning from Go to Show; playback state is retained across that navigation.
- Pointer focus and press feedback are improved for player controls, chapter/info cards, and submenu headers.
- Poster hover focus, end-of-list scrolling, and hold-to-open behavior are more consistent across Home and library pages.
- Profile and account navigation now returns correctly, and exit/sign-out prompts handle focus above the underlying screen.
- Seeking feedback and HUD clock placement/appearance are aligned with the player controls.

## Compatibility
- No release-specific playback test on a television is recorded for v0.9.3. Automated checks and simulator replays do not establish playback behavior on a television.

## Known issues
- No new device-specific issue is established by the available v0.9.3 evidence. This is not evidence that every television or media file is defect-free.
